**UberTutorial** 🚖  

This is a fully functional Uber clone built with Swift and Firebase. The project is developed using programmatic UI without storyboards, following best practices in iOS development.  

## 📌 **Features**  

- **User Authentication**: Sign up and sign in using Firebase Authentication.  
- **Real-Time Ride Requests**: Passengers can request rides, and drivers can accept or decline in real-time.  
- **Map Integration**: Displays real-time locations of users and routes using MapKit.  
- **Firebase Firestore**: Stores user profiles, ride requests, and other dynamic data.  
- **Geolocation & Tracking**: Updates driver and passenger locations in real-time.  
- **Push Notifications**: Notifies drivers of new ride requests.  
- **Custom UI Components**: Fully programmatic UI without using storyboards.  

## 🛠 **Technologies Used**  

- **Swift** - Core programming language  
- **UIKit** - UI framework for building the interface programmatically  
- **Firebase Authentication** - Handles user authentication  
- **Firebase Firestore** - Real-time NoSQL database for ride management  
- **MapKit** - Apple's framework for map rendering and location services  
- **CoreLocation** - Used for location tracking and geofencing  
- **GeoFire** - Efficient location querying within Firestore  

## 🚀 **Getting Started**  

1. Clone the repository:  
   ```bash
   git clone https://github.com/MYarovoi/UberTutorial.git
   ```  
2. Open the project in Xcode.  
3. Install dependencies and set up Firebase:  
   - Create a Firebase project and configure Authentication & Firestore.  
   - Download and add `GoogleService-Info.plist` to the project.  
4. Run the app on a simulator or real device.
